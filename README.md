# Детекция фишинговых сайтов с использованием методов машинного обучения
Курсовая работа по теме "Детекция фишинговых сайтов с использованием методов машинного обучения"

В условиях цифровой трансформации и роста онлайн-сервисов наблюдается значительный рост киберпреступности. Мошеннические веб-сайты становятся одним из основных инструментов злоумышленников для кражи конфиденциальных данных пользователей (логинов, паролей, банковских реквизитов), распространения вредоносного программного обеспечения и совершения финансовых махинаций. Существующие методы защиты часто отстают от быстро эволюционирующих тактик мошенников, что создает острую потребность в разработке современных, эффективных и автоматизированных решений. В нашем проекте мы делаем упор на создание решения для сайта московской биржи. В рамках проекта мы хотиим использовать методы машинного обучения для детекции таких сайтов. 

## Датасеты 
Для обучения модели для определения фавиконки был использован датасет с фавиконками: https://www.kaggle.com/datasets/colinmorris/favicons.   
Для обучения ЙОЛО модели был использован датасет из скринов с сайтов с помощью scraper.py на доменах, предоставленные мосбиржи.
